# 2026-11-27 分页与搜索 + 沙箱 SSH 密钥持久化

## 1. 为什么做

文档数量一旦上百，原来两处都是"一次性渲染全部"：索引页把所有条目铺出来、管理页把整张表塞进浏览器，页面会变慢；更严重的是 `listDocs()` 只取 `max-keys=1000` 且不翻页，**超过 1000 个对象会静默丢数据**。

## 2. 做了什么

- 新增 `listPrefix(env, prefix)`：用 `continuation-token` 翻页取全量（每前缀上限 5000），结果按上传时间倒序，在 Worker 内存缓存 30 秒
- 新增 `invalidateList()`：上传、删除成功后立刻清缓存，避免"传了看不到"
- 新增 `pickPage(url, items)`：统一做 `q` 子串筛选（不区分大小写）+ `page/size` 分页；`size` 限制 10–100，默认 20，`page` 越界归一到最后一页
- 文档中心 `/`、`/private` 增加搜索框与分页条，纯服务端 GET，无 JS 也能用，URL 可收藏
- 管理页 `/admin` 增加搜索（防抖 300ms）、级别/类型筛选、分页，表格加了"上传时间"列
- 图库 `/g` 同步加分页与搜索
- `/list-docs`、`/list` 接口支持 `scope / type / prefix / q / page / size`

## 3. 验证记录

- 上传 22 篇测试文档后：`共 22 篇`；`size=10` 时第 1 页为 testp-22/21…，第 2 页 testp-12/11…，`page=99` 归一到第 3 页
- `q=testp-1` 命中 10 篇，`q=zzzz` 显示"没有匹配的文档"
- `/list-docs?scope=private` 只返回 2 个私有文档；无密钥返回 401
- 测试文档已全部删除，桶内恢复为 2 私有文档 + 3 公开图片

## 4. 经验

- B2 的 `ListObjectsV2` 单次最多 1000 条，**必须处理 `NextContinuationToken`**，否则大数据量静默截断
- 缓存能省 B2 调用，但写后必须失效，否则用户会觉得"上传没生效"；30 秒 TTL + 写时清理是折中

## 5. 沙箱 SSH 密钥

- 根因：沙箱重建会清空 `~/.ssh`，之前生成的私钥丢失，所以每次都要在 ECS 重新加公钥
- 处理：私钥持久化到 `/workspace/.secrets/ssh/hw_ed25519`（`/workspace/.gitignore` 已忽略 `.secrets/`），新会话从这里拷回 `~/.ssh/id_ed25519`
- 连接需走沙箱代理：`ProxyCommand nc -X connect -x 127.0.0.1:18080 %h %p`
